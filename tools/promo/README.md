# @funfactory/promo

Promo clips for the games (Remotion): intro animation, gameplay cuts with captions, end card, music.
How to make a clip (in Polish): `docs/promo.md`.

```sh
pnpm promo                                                    # Remotion Studio (preview, edit props)
pnpm --filter @funfactory/promo exec remotion render GlutPromoPL out/glut-promo-pl.mp4
```
