# Ostatnia Brama

Gra Funfactory. Kod gry jest w `src/`, a wspólne rzeczy w `packages/`.

```sh
pnpm --filter @funfactory-game/ostatnia-brama dev   # przeglądarka
pnpm shot games/ostatnia-brama                       # zrzuty z telefonu (Playwright)
pnpm --filter @funfactory-game/ostatnia-brama ios    # Xcode
pnpm --filter @funfactory-game/ostatnia-brama android
```
