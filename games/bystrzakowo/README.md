# Bystrzakowo

Gra Funfactory. Kod gry jest w `src/`, a wspólne rzeczy w `packages/`.

```sh
pnpm --filter @funfactory-game/bystrzakowo dev   # przeglądarka
pnpm shot games/bystrzakowo                       # zrzuty z telefonu (Playwright)
pnpm --filter @funfactory-game/bystrzakowo ios    # Xcode
pnpm --filter @funfactory-game/bystrzakowo android
```
