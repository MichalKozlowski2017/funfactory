# Glut

Gra Funfactory. Kod gry jest w `src/`, a wspólne rzeczy w `packages/`.

```sh
pnpm --filter @funfactory-game/glut dev   # przeglądarka
pnpm shot games/glut                       # zrzuty z telefonu (Playwright)
pnpm --filter @funfactory-game/glut ios    # Xcode
pnpm --filter @funfactory-game/glut android
```
